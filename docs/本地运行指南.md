# 本地运行指南

在仓库根目录执行下列命令，使用 Python 3.10 或更高版本。Windows 的首次安装见 [README 的快速体验](../README.md#快速体验)。下文中的 `python` 指当前虚拟环境的解释器。在 Windows 上，也可以直接使用 `.\.venv\Scripts\python.exe`。

## RailPolicy RAG Studio V1

在 macOS 或 Linux 上，从已克隆的仓库根目录启动。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[ui]'
python -m streamlit run ui/app.py
```

打开 [本地 Studio](http://127.0.0.1:8501)。「知识库浏览」可以按 FAQ、须知和规程查看原文，条目也可带入问答。初始检索策略为重排。只安装 UI 时，到「检索调试」选择 BM25 即可开始查询，浏览和 BM25 检索无需 API Key。

## 配置 DeepSeek

在启动 Streamlit 的同一个 PowerShell 窗口中设置 `DEEPSEEK_API_KEY`。如果界面已经启动，设置后重新运行启动命令。

```powershell
if (-not $env:DEEPSEEK_API_KEY) {
    $railKey = Read-Host "DeepSeek API Key" -AsSecureString
    $env:DEEPSEEK_API_KEY = [System.Net.NetworkCredential]::new('', $railKey).Password
    Remove-Variable railKey
}
.\.venv\Scripts\python.exe -m streamlit run ui/app.py
```

在 Bash 中可以用 `read -rs -p 'DeepSeek API Key: ' DEEPSEEK_API_KEY` 读取密钥，再执行 `export DEEPSEEK_API_KEY` 和 Streamlit 启动命令。

在「问答测试」选择纯 RAG、原生 Agent 或 LangGraph V1。使用 LangGraph V1 前，在同一个环境运行 `python -m pip install -e ".[ui,langgraph]"`。点击「发送」后，程序会把问题和流程取得的证据发送给 DeepSeek，Agent 可能在预算内调用模型多次。每次问答的 JSONL 轨迹保存在 `results/studio_traces/`，其中包含问题、工具参数与证据。

## 可选检索依赖

| 检索策略 | 在 UI 环境中安装 |
| --- | --- |
| BM25 | `python -m pip install -e ".[ui]"` |
| BGE Embedding 或 BM25 + BGE + RRF | `python -m pip install -e ".[ui,embedding]"` |
| RRF + Cross-Encoder Reranker | `python -m pip install -e ".[ui,reranker]"` |

同时使用重排和 LangGraph 时，可以安装 `.[ui,langgraph,reranker]`。BGE 与重排需要对应模型权重。已有 Hugging Face 缓存时，可在启动前用 `HF_HOME` 指定缓存根目录。离线运行 ONNX 重排时，在「检索设置 → 高级选项 → 重排模型」填入包含 `config.json` 和 `onnx/` 的本地模型快照目录。

初始 Top-K 为 3。纯 RAG 和检索调试使用界面 Top-K，Agent 可以指定工具 Top-K，省略时使用工具默认值 3。执行过程会显示每次调用的请求值与实际返回数量。准备索引、执行检索和模型调用的耗时可以在「查看运行统计」中分别查看。

Studio 优先从本机 Hugging Face 缓存加载 BGE。文档切块及 BGE 配置一致时，BGE、RRF 和重排共享编码器与文档向量。此前使用本机缓存权重并拦截 HTTP 请求验证，首次准备 RRF 索引约 16 秒，随后切到 BGE 时索引准备约 10 毫秒，单次 BGE 查询约 11 毫秒。

## 命令行

以下示例使用铁路 BM25 配置。只运行终端命令时，基础依赖可用 `python -m pip install -e .` 安装。

```powershell
python -m domainrag.cli query --config configs/railway_dev_bm25.json --question "改签后可以退票吗？"
python -m domainrag.tools --config configs/railway_dev_bm25.json search_knowledge --query "改签后可以退票吗？"
```

配置 `DEEPSEEK_API_KEY` 后，可从终端调用纯 RAG 或原生 Agent。

```powershell
python -m domainrag.cli answer --config configs/railway_dev_bm25.json --provider deepseek --question "改签后可以退票吗？"
python -m domainrag.agent --config configs/railway_dev_bm25.json --question "改签后可以退票吗？"
```

### LangGraph Agent V1

```powershell
python -m pip install -e ".[langgraph]"
python -m domainrag.langgraph_cli --help
python -m domainrag.langgraph_cli --config configs/railway_dev_bm25.json --question "改签后可以退票吗？"
```

图版与原生 Agent CLI 共用参数和默认值，均输出 JSON 与本地 JSONL 轨迹。完成或合法拒答返回退出码 0，预算停止或失败返回 1。Python 调用方可通过 `AgentLimits.max_context_chars` 设置上下文预算。 [状态与执行细节](项目数据流与面试复习.md#8-langgraph-agent-v1)
