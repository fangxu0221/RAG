## 3. 提取与完整性

- FAQ：由官网帮助页元素ID及官方 `help.js` 的跳转方式定位页面；提取 `.q-list` 中成对的 `dt/dd`。保留原问题编号与答案内容，校验题号连续、答案非空及正文字符未丢失。
- 须知：原HTML是Vue壳页面，正文在官网引用的版本化JavaScript包中。只用JSON解析器读取静态 `rules` 字符串数组，不执行下载的JavaScript，也不执行其第三方脚本。
- 规程：保留章节、节与连续第1—115条的原文顺序，排除HTML注释中的旧内容、页头导航和其他隐藏规则。转换后核对正文非空白字符一致。
- `sources.json`：记录官方URL、实际正文资源URL、采集UTC时间、HTTP状态、可用的Last-Modified/ETag、原始响应SHA256、正文与Markdown哈希、版本ID、单位数、提取方式和待审核状态。
- `units.jsonl`：每个证据单元有稳定ID、所属文档、官方URL、原文段落、文本哈希及在Markdown中的字符区间。该区间是转换后Markdown的Python字符偏移，不是网页字节偏移，也不是规范化后的Chunk偏移。
- 规程的购票、优惠票、查验、乘车、改签和退票条款以 `priority_article_numbers/priority_unit_ids` 索引。全文均保留，当前没有据此改变检索排序权重。

这一步保证来源和转换过程可追踪，尚未逐条裁定FAQ、须知与规程间是否一致。后续应结合版本日期和适用范围审核，不能仅因来自官网就把不同时间、不同范围的条文拼成统一结论。

## 4. 复现和离线校验

采集器是独立脚本 [collect_railway_v1.py](../scripts/collect_railway_v1.py)，依赖只用于采集，不加入基础问答运行依赖。

```powershell
python -m pip install -e ".[collection]"
python -B -X utf8 scripts/collect_railway_v1.py --verify-only
```

`--verify-only` 不联网，检查13个原始响应、九份Markdown、197个证据单元的内容哈希、单位数量和Markdown定位。正式采集命令为 `python scripts/collect_railway_v1.py`；当前目录已有 `sources.json`，脚本会拒绝覆盖它。需要新版本时使用独立输出目录并审核新快照，不修改旧快照来掩盖来源变化。
